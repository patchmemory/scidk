Connections

Every graph backend SciDK talks to. Configuration is read on page load; connectivity and counts are checked on demand.

About these backends

SciDK keeps its data in separate graph stores so that research data, chat provenance, and the system's own self-knowledge can be backed up, shared, and reasoned about independently.

Test Connection uses the same client factory a real query would use, so a green result means the app can actually read from that backend — not merely that the port is open.

Node/edge counts are full-store aggregates (MATCH (n) RETURN count(n)). They are loaded on demand because they are not cheap on a large graph.
