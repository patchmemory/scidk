Scanner

How much parallelism scans may use, and how many may run at once.

Total I/O workers across all running scans. Workers are split across top-level subdirectories, so requesting 32 workers on a path with 5 subdirs uses at most 5. 16–32 is recommended for CIFS/NFS network mounts.
Scans beyond this limit queue and start as workers free up. Note that SCIDK_MAX_BG_TASKS also caps how many tasks may run at once, so it has to be at least this large for the value to take effect.
